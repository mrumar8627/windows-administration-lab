# Windows Administration Lab

Practical beginner-level labs covering Windows administration, system information, user management, permissions, software installation, storage, and troubleshooting.

This repository documents my hands-on learning and practical preparation for an **Ausbildung als Fachinformatiker für Systemintegration** in Germany.

---

## Topics Covered

### Windows Basics

- System Information
- Task Manager
- Device Manager
- Windows Update

### Users & Permissions

- Local User Accounts
- File and Folder Permissions
- Shared Folders

### Windows Administration

- Software Installation
- Disk Management
- Event Viewer

### Troubleshooting

- Basic Windows Troubleshooting
- System Performance
- Hardware and Software Issues
