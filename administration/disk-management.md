# Windows Disk Management

## Objective

To understand how Windows Disk Management can be used to view and manage storage devices and partitions.

---

## What Is Disk Management?

Disk Management is a Windows administration utility used to view information about storage devices, partitions, and volumes.

It can help an IT support technician understand how storage is organized on a computer.

---

## Opening Disk Management

### Method 1

Press:

Windows + X

Then select:

Disk Management

### Method 2

Press:

Windows + R

Type:

diskmgmt.msc

Press Enter.

---

## Information Available

Disk Management can display:

- Physical disks
- Partitions
- Volumes
- File systems
- Drive letters
- Unallocated space
- Disk status

---

## Common Storage Terms

### Disk

A physical storage device such as an SSD or HDD.

### Partition

A logical division of a physical disk.

### Volume

A formatted storage area that Windows can use.

### Unallocated Space

Disk space that is not currently assigned to a partition.
