# Windows Event Viewer

## Objective

To understand how Event Viewer can be used to investigate system and application events in Windows.

---

## What Is Event Viewer?

Event Viewer is a Windows administration tool that displays recorded events generated by the operating system and applications.

IT support technicians can use these events as part of troubleshooting.

---

## Opening Event Viewer

Press:

Windows + R

Type:

eventvwr.msc

Press Enter.

---

## Common Event Logs

Event Viewer commonly contains logs such as:

- Application
- Security
- System
- Setup

The available logs can vary depending on the Windows configuration.

---

## Event Types

Windows events may have different levels.

Common levels include:

- Information
- Warning
- Error
- Critical

An error does not always mean that the entire system has failed. It should be investigated together with the time, source, event ID, and other details.

---

## Investigating an Event

When troubleshooting:

1. Open Event Viewer.
2. Select the relevant log.
3. Find the event related to the problem.
4. Check the event level.
5. Check the source.
6. Note the Event ID.
7. Review the event description.
8. Compare the event time with when the problem occurred.

---

## Example

Suppose an application crashes at 10:30 AM.

An IT support technician can check the Application log around that time and look for related errors.

This information can provide additional clues for troubleshooting.
