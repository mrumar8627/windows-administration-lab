# Windows Software Installation

## Objective

To understand the correct process of installing, configuring, updating, and removing software on a Windows computer.

---

## What Is Software Installation?

Software installation is the process of adding an application or program to a computer so that it can be used by the user.

IT support technicians may install software based on user requirements and organizational policies.

---

## Before Installing Software

Before installing an application, check:

- Is the software required?
- Is it compatible with the Windows version?
- Does the computer meet the system requirements?
- Is enough storage space available?
- Is the software from a trusted source?
- Is administrator permission required?
- Is the software approved by the organization?
