# Windows Device Manager

## Objective

To use Device Manager to identify hardware devices and check for driver-related problems.

---

## What Is Device Manager?

Device Manager is a Windows administration tool used to view hardware devices installed on a computer.

It can help identify problems with hardware devices and their drivers.

---

## Opening Device Manager

### Method 1

Press:

Windows + X

Then select:

Device Manager

### Method 2

Press:

Windows + R

Type:

devmgmt.msc

Press Enter.

---

## Device Categories

Device Manager can display categories such as:

- Display adapters
- Network adapters
- Processors
- Disk drives
- Keyboards
- Mice and other pointing devices
- Sound, video and game controllers

---

## Checking a Device

Select a device category and expand it.

Right-click a device and select:

Properties

The Properties window may provide information about:

- Device status
- Driver information
- Device details
- Resources

---

## Driver Problems

A hardware device may not work correctly if its driver is:

- Missing
- Corrupted
- Incompatible
- Outdated

Windows may display an indicator next to a device when there is a problem.

---

## Basic Troubleshooting

When a hardware device is not working:

1. Open Device Manager.
2. Find the relevant device.
3. Check its status.
4. Open Properties.
5. Review the available information.
6. Check the driver information.
7. Investigate the hardware or driver issue.

Do not remove or modify drivers without understanding the possible effects.
