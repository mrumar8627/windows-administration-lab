# Windows Task Manager

## Objective

To learn how to use Windows Task Manager to monitor applications, processes, and system performance.

## What Is Task Manager?

Task Manager is a built-in Windows tool used to monitor running applications and processes.

It can also help an IT support technician identify basic performance problems.

## Opening Task Manager

### Method 1

Press:

Ctrl + Shift + Esc

### Method 2

Right-click the taskbar and select:

Task Manager

### Method 3

Press:

Ctrl + Alt + Delete

Then select:

Task Manager

## Processes

The Processes section displays applications and background processes currently running on the computer.

It provides information about resource usage such as:

- CPU
- Memory
- Disk
- Network
- GPU

## Performance

The Performance section provides an overview of system resources.

Commonly displayed resources include:

- CPU
- Memory
- Disk
- Ethernet or Wi-Fi
- GPU

This information can help identify possible performance problems.

## Startup Apps

The Startup Apps section shows applications that can start automatically when Windows starts.

Too many startup applications may increase startup time.

Before disabling a startup application, its purpose should be understood.

## Ending an Unresponsive Application

If an application stops responding:

1. Open Task Manager.
2. Go to Processes.
3. Find the unresponsive application.
4. Select the application.
5. Choose End task.

Only end processes when their purpose is understood because ending important system processes may cause problems.

## Basic Performance Troubleshooting

If a computer is running slowly:

1. Open Task Manager.
2. Check CPU usage.
3. Check memory usage.
4. Check disk usage.
5. Identify applications using unusually high resources.
6. Investigate the application or process.
7. Take an appropriate troubleshooting action.
8. Check whether system performance improves.

## Example

A user reports that their computer is very slow.

The IT support technician can check Task Manager:

CPU Usage: 25%
Memory: 90%
Disk: 15%

High memory usage may indicate that too many applications or processes are running.

Further investigation is required before deciding on a solution.

## Important Note

Task Manager shows current system activity. High resource usage does not automatically mean that a process is faulty.

The process, application, and situation should be investigated before taking action.
