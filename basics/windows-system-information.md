# Windows System Information

## Objective

To identify and review basic hardware and operating system information on a Windows computer.

---

## Why System Information Is Important

IT support technicians often need to identify a computer's hardware and operating system before troubleshooting a problem.

Important information can include:

- Windows version
- Processor
- Installed RAM
- System type
- Computer name
- Storage devices
