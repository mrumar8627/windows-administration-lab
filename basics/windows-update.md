# Windows Update

## Objective

To understand how Windows Update helps maintain system security, stability, and compatibility.

---

## What Is Windows Update?

Windows Update is a Windows service used to deliver updates for the operating system and supported Microsoft software.

Updates can include:

- Security updates
- Bug fixes
- Feature updates
- Driver updates
- Quality improvements

---

## Checking for Updates

Open:

Settings → Windows Update

Select:

Check for updates

Windows will check whether updates are available.

---

## Why Updates Are Important

Keeping Windows updated can help:

- Fix known software problems
- Improve system stability
- Address security vulnerabilities
- Improve compatibility
- Maintain supported system components

---

## Basic Update Procedure

1. Open Windows Settings.
2. Go to Windows Update.
3. Select **Check for updates**.
4. Review available updates.
5. Install updates when appropriate.
6. Restart the computer if required.
7. Check Windows Update again after restarting.

---

## Troubleshooting

If Windows Update is not working correctly, basic checks include:

- Check the Internet connection.
- Restart the computer.
- Check available storage space.
- Check Windows Update settings.
- Review any displayed error message.

For persistent problems, additional troubleshooting may be required.
