# Basic Windows Troubleshooting

## Objective

To follow a structured process for identifying and troubleshooting common Windows problems.

## What Is Troubleshooting?

Troubleshooting is a systematic process of identifying a problem, finding its possible cause, applying an appropriate solution, and verifying the result.

A structured approach helps avoid unnecessary changes to the system.

## Step 1: Identify the Problem

First, understand the user's problem.

Ask questions such as:

- What is not working?
- When did the problem start?
- Was anything changed recently?
- Is there an error message?
- Does the problem affect one user or multiple users?

Record the relevant information.

## Step 2: Perform Basic Checks

Start with simple checks.

Check:

- Power
- Cables
- Network connection
- Device connections
- Available storage
- Software status
- Windows updates

Restarting the computer can also resolve some temporary problems.

## Step 3: Check System Information

Review the computer's hardware and Windows configuration when necessary.

Useful tools include:

msinfo32

and:

systeminfo

These tools can provide information about the operating system and hardware.

## Step 4: Check Task Manager

If the computer is slow:

1. Open Task Manager.
2. Check CPU usage.
3. Check memory usage.
4. Check disk usage.
5. Check running applications.
6. Identify unusual resource usage.

Further investigation may be required before taking action.

## Step 5: Check Device Manager

If the problem involves hardware:

1. Open Device Manager.
2. Find the relevant device.
3. Check the device status.
4. Review driver information.
5. Investigate possible hardware or driver problems.

## Step 6: Check Windows Update

If a Windows feature or application is not working correctly:

1. Open Windows Update.
2. Check for available updates.
3. Review any update errors.
4. Install appropriate updates.
5. Restart the computer if required.
6. Test the problem again.

## Step 7: Check Event Viewer

For certain system or application problems:

1. Open Event Viewer.
2. Select the relevant log.
3. Look for related warnings or errors.
4. Check the event time.
5. Note the source and Event ID.
6. Review the event description.

Event Viewer can provide additional information about system and application problems.

## Step 8: Apply an Appropriate Solution

After identifying a possible cause:

- Apply the appropriate fix.
- Avoid unnecessary system changes.
- Follow organizational procedures.
- Make sure important data is protected.
- Record the action taken.

## Step 9: Test the Solution

After applying a solution:

1. Test the affected function.
2. Ask the user to confirm the result when appropriate.
3. Check whether the original problem is resolved.
4. Check for any new problems.

## Troubleshooting Flow

Identify Problem
       ↓
Basic Checks
       ↓
Gather Information
       ↓
Check System / Task Manager / Device Manager
       ↓
Check Updates or Event Logs
       ↓
Identify Possible Cause
       ↓
Apply Appropriate Solution
       ↓
Test
       ↓
Document

## Example: Slow Computer

### Problem

A user reports that the computer is running slowly.

### Investigation

Check:

- Task Manager
- CPU usage
- Memory usage
- Disk usage
- Startup applications
- Available storage
- Windows updates

### Possible Causes

Possible causes may include:

- Too many applications running
- High memory usage
- Limited storage space
- Background processes
- Pending updates
- Software-related problems

### Result

After applying an appropriate solution, test the computer again and confirm whether performance has improved.

## Documentation

A troubleshooting record can include:

Problem:
Date:
User:
Symptoms:
Checks Performed:
Findings:
Possible Cause:
Action Taken:
Result:
Additional Notes:

Do not record sensitive information such as passwords in troubleshooting documentation.
