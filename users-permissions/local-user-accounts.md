# Local User Accounts in Windows

## Objective

To understand the purpose of local user accounts and basic user account management in Windows.

---

## What Is a Local User Account?

A local user account is an account that exists directly on a Windows computer.

It can be used to sign in and access files, applications, and system resources according to the assigned permissions.

---

## Common Account Types

Windows can have different levels of user access.

### Standard User

A standard user can perform normal tasks such as:

- Running applications
- Creating personal files
- Changing certain personal settings

### Administrator

An administrator has higher privileges and can perform system-level tasks such as:

- Installing software
- Changing system settings
- Managing user accounts
- Configuring certain Windows features

Administrator access should be used carefully.
